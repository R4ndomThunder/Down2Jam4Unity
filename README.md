# Description
A Unity Package to use the Down2Jam api for you jam entries.

# How to install

### Using **Unity Package Manager**
- Open the Unity Package Manager  
- Click on `+` icon 
- Select `Install Package from git URL...` 
- Paste `https://github.com/R4ndomThunder/Down2Jam4Unity.git` 
- Click `Install`
- Wait & Enjoy! :D

### Using **Manifest.json**
- Open your manifest.json file @`Packages/manifest.json`
- Add this line into the file
```json 
"dev.samuelepadalino.down2jam4unity": "https://github.com/R4ndomThunder/Down2Jam4Unity.git"
```
- Save the file
- Wait & Enjoy! :D
